# Personal website

A simple, fast static site (plain HTML + CSS, no build step) hosted on GitHub Pages.

- Edit content in `index.html` — look for the `<!-- ===== -->` section markers and replace the "Your Name" placeholders.
- Edit colors and fonts in `style.css` (the `:root` variables at the top).
- Push to `main` and GitHub Pages republishes automatically within a minute or so.

Live site: https://personal-website-beta-bice-85.vercel.app (auto-deploys from `main` via Vercel).
